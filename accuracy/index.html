How the check works

At 7 minutes past every hour, Pass Checker reads each region's official feed fresh and compares it with the status the app was showing at that same moment. If they differ, it is a mismatch and it is listed above, with no exceptions. Pass data in these regions refreshes every 10 minutes, so most mismatches are a road that changed status in the minutes before the check.

What this covers

These seven regions publish feeds Pass Checker reads directly, so they can be checked automatically: Washington (WSDOT), British Columbia (DriveBC), Colorado (CDOT), California (Caltrans), Utah (UDOT), Idaho (Idaho 511) and Arizona (AZ511). Other regions are not included in this report. Pass Checker can only be as current as the DOT itself; always confirm with the official source before you travel.
